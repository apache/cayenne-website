Connecting to a Database

The mapping project does not contain any database connection information. The database is defined in the code, when the runtime is created, as a DataNode. In the simplest case a DataNode is created from a DataSource. It can be any DataSource, e.g., the one provided by your application container, or the one built with CayenneDataSource:

DataSource dataSource = CayenneDataSource.of("jdbc:hsqldb:mem:starting")
        .userName("sa")
        .password("")
        .pool(1, 5)
        .build();

CayenneRuntime runtime = CayenneRuntime.of()
        .addConfig("cayenne-project.xml")
        .defaultDataNode(dataSource)
        .build();

When a DataNode needs to be customized, e.g., to let Cayenne create the DB schema on the first connection, to set a specific DbAdapter, or to give the node a name, use a DataNodeDescriptor:

DataNodeDescriptor node = DataNodeDescriptor.of("node1")
        .dataSource(dataSource)
        .createSchemaIfNeeded()
        .build();

CayenneRuntime runtime = CayenneRuntime.of()
        .addConfig("cayenne-project.xml")
        .defaultDataNode(node)
        .build();

There can be more than one DataNode. Each one is linked to its DataMaps by name. The "default" DataNode is optional, and is used for all the DataMaps that are not linked to a node explicitly:

CayenneRuntime runtime = CayenneRuntime.of()
        .addConfig("cayenne-project.xml")
        .addDataNode(ds1, "docs")
        .defaultDataNode(ds2)
        .build();
