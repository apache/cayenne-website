DataNode

DataNode is a model of a database. It is actually pretty simple. It has a name and a JDBC DataSource. Unlike the rest of the objects discussed here, DataNodes are not a part of the XML mapping project. They are defined in the code, when Cayenne runtime is created (see Starting Cayenne). Most applications only have one DataNode, though there may be any number of nodes if needed.
