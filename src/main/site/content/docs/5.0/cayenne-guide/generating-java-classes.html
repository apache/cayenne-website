Generating Java Classes

Before using Cayenne in you code you need to generate java source code for persistent objects. This can be done with Modeler GUI or via cgen maven/ant plugin.

To generate classes in the Modeler select a DataMap, go to the Class Generation tab and click Generate.

The default settings are suitable for almost all cases. Change them only if you know what exactly you need to customize. The "Advanced options" and "Templates options" on the same tab let you control almost all aspects of code generation, including custom templates for Java code. See default Cayenne templates on GitHub as an example.
